# Hogicam: Digital Camera — Privacy Policy and Terms of Use

Public home of the legal pages for the Android app `vn.txclabs.digicam`, served with GitHub Pages
(`main` branch, root folder):

- `privacy-policy.html` — https://tangxuanchien.github.io/digicam-privacy-policy/privacy-policy.html
- `terms.html` — https://tangxuanchien.github.io/digicam-privacy-policy/terms.html
- `index.html` — redirects to the privacy policy, for app versions that linked the site root.

Both pages are bilingual (EN / VI, `?lang=en|vi`). This repository only holds the pages; the app's source code lives
in a private repository, where this repo is cloned at `policy/` and git-ignored.
